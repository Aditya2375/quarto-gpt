What is inside

Three pre-normalized decoder blocks, four causal attention heads per block, width 96, learned position embeddings, GELU feed-forward layers and a character prediction head. Trained from scratch with AdamW for 1,500 steps, batch 24, context 96 and seed 410. There is no pretrained model or remote inference service.

Where the text comes from

Tiny Shakespeare, the public-domain Shakespeare excerpt corpus used in character-model tutorials. The architecture follows standard causal-transformer practice; see Karpathy's build-GPT lecture. Training code here is a compact implementation, not a claim to have invented the architecture.
