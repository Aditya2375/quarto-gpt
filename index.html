Supported characters and context rules

Only the listed characters are accepted. Curly quotes, emoji and accented letters are rejected, not rewritten. Each prediction sees at most the last 96 characters. Longer text slides this window, with positions reset. Prompts stay in memory and disappear on reload.

Silence one head

A real inference-time intervention, with no retraining. The selected head's weighted-value output is set to zero before the attention output projection at every position. No text or weights are edited. The effect is on this opening only; it does not prove what the head "means". Sampling above always uses the unmodified models.

The complete notebook

Three pre-normalized causal decoder blocks, width 96, four heads each. Learned positions, GELU-tanh feed-forward layers, LayerNorm, and a 65-way character head. No pretrained weights.

Edition II keeps the architecture and initialization seed 410. AdamW, batch 24, weight decay 0.01, gradient clip 1, cosine learning rate 0.0007 to 0.00007 over 6,000 updates. Training and evaluation use separate random generators. Resuming restores both generators and the optimizer.

The model can repeat itself, invent words, and lose the thread. A contiguous excerpt split can share phrases, characters and works. Lower validation loss does not prove leak-free generalization or usefulness as a conversational model.
